# 개념 정리

각 주제는 `.md` 파일 하나. `_template.md` 복사해서 시작한다.

```bash
cp concepts/_template.md concepts/data-structure/stack.md
```

## 자료구조 (`data-structure/`)

- [ ] `array.md` 배열 / 동적 배열
- [ ] `linked-list.md` 연결 리스트
- [ ] `stack.md` 스택
- [ ] `queue.md` 큐
- [ ] `deque.md` 덱
- [ ] `hash.md` 해시 테이블 (Map / Set)
- [ ] `heap.md` 힙 / 우선순위 큐
- [ ] `tree.md` 트리, 이진 탐색 트리
- [ ] `trie.md` 트라이
- [ ] `graph.md` 그래프 표현 (인접 행렬 / 리스트)
- [ ] `union-find.md` 유니온 파인드
- [ ] `segment-tree.md` 세그먼트 트리
